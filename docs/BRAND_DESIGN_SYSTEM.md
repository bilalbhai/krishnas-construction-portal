# Brand design system

Source: the supplied official PNG logo, inspected and sampled on 25 October 2026. The image has a textured/antialiased gold gradient rather than a single flat gold.

| Token      | HEX       | Application                                                                         |
| ---------- | --------- | ----------------------------------------------------------------------------------- |
| Charcoal   | `#1F1F1F` | Dominant background sampled from logo; sidebar, login identity panel, PDF header    |
| Gold       | `#C28F42` | Sampled architectural linework; active navigation, fine rules and document headings |
| Warm peach | `#FFCFAE` | Sampled lettering highlight; sidebar brand text                                     |
| Paper      | `#F7F6F2` | Warm neutral canvas                                                                 |
| Ink        | `#262923` | Readable dark content                                                               |
| Muted      | `#6E7369` | Secondary text                                                                      |
| Border     | `#E3E4DB` | Quiet content boundaries                                                            |

Paper/ink/muted/border are supporting neutrals, not claimed official logo colours. Status colours are reserved for functional information; gold is not used for low-contrast body text on white.

Manrope headings and DM Sans body, with system sans-serif fallbacks. Main headings 25–30 px, forms 12–15 px, inputs at least 44–45 px tall. PDF typography uses embedded standard PDF Helvetica/Helvetica Bold for sharp selectable text. PDF body 9 pt, heading 19–25 pt.

The actual logo is preserved without changing its artwork or palette. Its charcoal background is retained. Default company mark is a rectangular charcoal/gold frame containing the logo and business ABN. It is a business mark, not a certification. Approval is required before use on issued documents.

Spacing follows a 4/8 px family with 15–24 px gaps, 20–30 px card padding and 8–11 px corner radii. Dashboard prioritises four quick actions over financial analytics. Separate document steps reduce form density. Mobile uses hidden navigation, stacked line-entry cards and sticky save/continue actions. All controls have labels, keyboard focus outlines and meaningful empty states. Destructive actions use explicit confirmation dialogs, not icon-only deletion.
